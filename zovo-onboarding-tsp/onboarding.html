a note from the person who built this

I built this because I kept catching myself doing the risky thing. Pasting a live API response into whatever formatter ranked first on Google, just to read it. That payload had tokens and customer data in it, and it went straight to a stranger's server. So I made the version I'd trust on my own machine. It parses everything locally, sends nothing, and every line sits on GitHub where you can read it yourself.

If a Chrome update breaks something, or you wish it did one more thing, tell me. Every bug and request is read and fixed by the same person who wrote the code. That's the deal. You use it, I keep making it better.
